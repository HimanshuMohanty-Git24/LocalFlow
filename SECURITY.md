# Security

LocalFlow is designed to run fully offline. Please do **not** report
transcripts, audio, or personal dictation samples in issues.

## Report a vulnerability

Use [GitHub Security Advisories](https://github.com/HimanshuMohanty-Git24/LocalFlow/security/advisories/new)
for anything that could leak audio, text, or allow unexpected network access.

We aim to respond within 14 days.
